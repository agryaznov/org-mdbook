* Introduction

Welcome to this sample documentation! This demonstrates the mdBook-style theme for org-mode HTML export.

The theme features:

- A toggleable sidebar with table of contents
- Multiple color themes (Light, Rust, Navy, Ayu)
- Responsive design for mobile devices
- Keyboard shortcuts for power users

** Getting Started

To use this theme, simply add the setup file to your org document:

#+begin_src org
#+SETUPFILE: path/to/org-mdbook.setup
#+end_src

Then export with =C-c C-e h h=.

** Method 1: Per-file Setup

1. Copy =org-mdbook.css=, =org-mdbook.js=, and =org-mdbook.setup= to your project directory

2. Add to your org file:
   #+begin_src org
   #+SETUPFILE: org-mdbook.setup
   #+end_src

3. Export with =C-c C-e h h=

** Method 2: Global Emacs Configuration

Add to your =init.el=:

#+begin_src emacs-lisp
;; Load org-mdbook
(add-to-list 'load-path "~/.emacs.d/org-mdbook/")
(require 'org-mdbook)

;; Set resources directory
(setq org-mdbook-resources-dir "~/.emacs.d/org-mdbook/")

;; Optional: embed resources in HTML (default: t)
(setq org-mdbook-embed-resources t)

;; Enable globally (or use org-mdbook-export-to-html for single files)
(org-mdbook-enable)
#+end_src

#+BEGIN_SRC rust
// Called for each PUT /store/{upload_id}/chunk/{n}
async fn write_chunk(
    tmp_dir: &Path,
    upload_id: &str,
    n: usize,
    mut body: impl Stream<Item = Result<Bytes, axum::Error>> + Unpin,
    expected_hex: &str,
) -> Result<(), AppError> {
    let path = tmp_dir.join(upload_id).join(format!("chunk_{n}"));
    let mut file = File::create(&path).await?;
    let mut hasher = Sha256::new();

    // Feed each incoming chunk simultaneously to disk and hasher —
    // single pass, no extra memory, no re-read from disk.
    while let Some(chunk) = body.next().await {
        let bytes = chunk?;
        hasher.update(&bytes);
        file.write_all(&bytes).await?;
    }
    file.flush().await?;

    let got = hex::encode(hasher.finalize());
    if got != expected_hex {
        tokio::fs::remove_file(&path).await.ok();
        return Err(AppError::HashMismatch {
            n,
            got,
            expected: expected_hex.to_string(),
        });
    }
    Ok(())
}
#+END_SRC



* Configuration

** Theme Options

The theme supports four color schemes:

1. *Light* - Default light theme
2. *Rust* - Warm, brownish theme inspired by Rust documentation
3. *Navy* - Dark blue theme
4. *Ayu* - Dark theme with amber accents

Users can switch themes using the paint palette icon in the menu bar.

** Customization

You can customize the CSS by modifying =org-mdbook.css=. Key CSS variables:

#+begin_src css
:root {
  --bg: #ffffff;           /* Background color */
  --fg: #333333;           /* Text color */
  --sidebar-bg: #fafafa;   /* Sidebar background */
  --link: #4183c4;         /* Link color */
  --code-bg: #fdf6e3;      /* Code block background */
}
#+end_src
